# Club Coven 無限アレンジ再生

## 準備

リポジトリ直下に「ClubCoven.mp3」が必要です。これは自身で用意してください。

## 起動

Windows で Python 3.11、Tkinter、PATH 上の FFmpeg を使用します。音声出力は sounddevice です。

```powershell
python -m pip install -r requirements.txt
python play.py
```

Windows ではタイトルバーの最小化ボタンでタスクトレイに格納され、再生は続きます。Club Coven のトレイアイコンをクリックするか、右クリックして「ウィンドウを表示」を選ぶと復元できます。アプリを終了するには、ウィンドウの閉じるボタンかトレイメニューの「終了」を使います。

GUI の初期シードは起動ごとにランダムに決まります。固定するには `--seed 44` のように指定できます。音量と編曲強度を変更すると、アプリの終了時にリポジトリ直下の `preferences.json` に保存し、次回起動時に復元します。

「再生」で冒頭から開始します。起動時にループ区間のラウドネスを測り、原曲ミックスに一定のゲインをかけて −17 LUFS にそろえます。原曲の強弱は保たれます。追加の合成音と打音には、それぞれの編曲ルールの音量を使います。「停止」では音を短くフェードアウトします。停止中にシードを変更できます。編曲強度は再生中にも変更でき、次の小節で適用します。0%は原曲ループ、低強度では軽い打音、高強度では大胆な変奏やブレイクも候補に入ります。

画面にはスタイル、パート、エネルギー、強度、原曲位置、再生経過時間、最近の切り替えを表示します。「強度操作を保存」で再現用JSONを書き出せます。同じ音源・設定・バージョンで、保存した操作を `python play.py --controls controls.json --preview replay.wav --seconds 180` で再現できます。音量スライダーは出力装置側の音量として扱い、WAVには反映しません。操作が256回を超えると書き出しは無効になります。

GUI を開かずに試聴 WAV を作る場合は次のコマンドを使います。400 秒版には、最初のスタイル切り替え（約168秒）と、その次の切り替え（約372秒）が入ります。強度を指定するには `--intensity 45` などを追加します。

```powershell
python play.py --seed 44 --preview ClubCoven-preview.wav --seconds 400
```

## 原曲の解析

ローカルのステレオ MP3（48 kHz、約 178.2 秒）を使用しました。

| 項目 | 結果 |
| --- | --- |
| テンポ・拍子 | オンセットの自己相関に 0.25、0.50、2.00、8.00 秒のピーク。0.50 秒を拍、2.00 秒を小節として 120 BPM、4/4 のグリッドを採用。 |
| 小節・フレーズ | 強い立ち上がりはおおむね 0.375 秒を起点とする 0.5 秒間隔。16.375 秒から編曲用の小節を数え、4 小節ごとに状態を評価。 |
| リズム | 低域・高域のアタックは主に拍と 8 分音符に集中。高域の短いアタックを 3 種抽出し、裏拍と 16 分裏に補助打音を配置。抽出片には元のミックスの成分が残る。 |
| ベース・和声 | 16.375 秒と 32.375 秒からの最初の小節は低域の強い音が C–A♯–A と続く。48.375 秒付近には F や B、64.375 秒以降には C、F、C♯ 周辺の低域成分が目立つ。これは各拍で強い周波数を拾った候補で、確定したベース採譜やコード進行ではない。 |
| 構成 | 冒頭から音量と帯域が段階的に増え、約 30 秒台のフィルを経て 8 秒前後のまとまりが続く。約 98 秒でフィルが再来し、166 秒付近から終盤の減衰に入る。 |
| ループ | 30.750–98.750 秒の 68 秒（34 小節）。接続直前の 65 ms の左右チャンネル波形の正規化相関は約 0.983。終端のフィルを始点直前の対応する波形にクロスフェードし、始点のサンプルに連続させる。 |

原曲寄りの区間では、旋律、和声、低域の動き、音色の重なりをステレオ録音のまま使います。旋律のノート列、コード名、独立した楽器ステムは確定していません。

## 手続き的な編曲

通常の再生では、長期スタイルが持つエネルギーと役割を使って、セクションの拍、旋律の扱い、ベース、和音、打音を組み合わせます。ベースと和音の発音位置は、強拍・裏拍の重みと楽器間の間隔を制約として、その場で生成します。モチーフの冒頭を反復し、後半で和音の位置やフレーズ末尾の発音を変えます。セクションの切り替えでは、最近32区間の拍・音色・発音密度・配置を使って、似た構成の選択確率を下げます。

原曲を残す区間では控えめな和音を添えます。新しい拍を組み立てる区間では原曲ミックスを消音し、推定した旋律と和声から合成音で再構成します。旋律は主題・間引きと休止・楽器間の応答・伴奏のみの間奏から選ばれます。間奏では、入口と出口の推定ベースと構成音が一致する指定箇所で、先行フレーズの和声へ回帰できます。編曲強度30%未満では従来の原曲寄りの処理を使います。

`--legacy` を付けると従来のアレンジを再生できます。旧方式との音声比較と長時間描画の結果は [編曲生成の比較](evaluation/generation.md) にあります。

## 原曲の扱いと旧方式

原曲のステレオ素材を直接使う方式は、音色と演奏のニュアンスを保ちやすく、ランタイムの負荷も小さくできます。ステム分離を使えばパートの出し入れが可能になる一方、この音源での分離品質は未評価です。MIDI とソフトウェア音源で再構成すると音符単位で変えられますが、編曲を成立させるには多声部の採譜と音色の作り込みが必要になります。この版ではステレオ素材と、同じ音源から抽出した短い打音を組み合わせています。

長期スタイルは、既定設定で再生開始から約168秒、その後は68秒のループを3周するごと（204秒）に切り替わります。休息・展開・上昇・最高潮・解放・回帰を確率的に行き来し、原曲の区切りと直近の演奏を参考に、長期スタイルの選択の重みを変えます。旧方式では次の表の演奏構成を使い、4小節ごとにベース・和音・打音の一部を変化させます。

| スタイル | 演奏内容 |
| --- | --- |
| 原曲寄り | 原曲のミックスを主役にして、打音や短いフィルを添える。 |
| 鍵盤風 | アタックのある鍵盤音で、低めの音と高めの音を交互に弾く。 |
| 撥弦風 | 短く減衰する音を裏拍に置く。 |
| シンセパルス | 低音域の短い音をシンコペーションで刻む。 |
| アンビエント | 原曲ミックスを下げ、立ち上がりの遅い高音を半小節ごとに置く。 |
| 旋律の鍵盤演奏 | 旋律の音順と発音位置を保ち、アタックのある鍵盤風の合成音でなぞる。 |
| 旋律のシンコペーション | 音順を保ち、次の音と重ならない箇所で一部の発音を 16 分音符ぶん遅らせる。 |
| なめらかな旋律 | 短い折り返し音を省いて長めの音でつなぎ、節目に 1 オクターブ下を重ねる。 |
| 旋律の応答 | 伸ばした音の後ろで、その音を左右の位置と音色を変えて返す。 |
| ベース・ブレイク | 原曲から推定した低音を刻み、短い打音を重ねる。 |
| 打音ブレイク | キックと高域の打音だけで小節を進める。 |
| 低音主体の展開 | ベース、打音、短い裏拍の伴奏で進め、次のスタイルでベースパターンを引き継いで旋律を戻す。 |

伴奏は起動時に原曲のスペクトルから拍ごとに拾った低音と上声の候補を使います。音色は合成音です。旋律には、ステレオ録音の高音域から 16 分音符単位で推定した音列を使います。音高候補の競合と持続から旋律の信頼度を、和音候補の差から和音の信頼度を推定します。曖昧な装飾音や和音は置換時に抑えます。周波数マスクで処理した伴奏は比較用に残しています。

- `track.json` に音源名、テンポ、拍の基準、ループ区間、アレンジの目標秒数（`arrangement_seconds`）、打音の抽出位置、原曲ミックスの目標ラウドネス（`target_lufs`）があります。
- `rules.json` に状態遷移の重み、打音の数と音量、候補位置、スタイルごとの伴奏パターン、音色、ミックス設定があります。`backing` の 2 項目で、推定した旋律の倍音と中域のピークを抑える強さを調整できます。位置は 1 小節を 16 分割した 0 始まりの番号です。
- `material.py` が起動時に音源を準備し、`arrangement.py` が次の小節を決め、`engine.py` が要求されたフレーム数だけ描画します。再生が進んでも過去の音声やアレンジ履歴を保持しません。GPU、生成 AI、外部 API は使いません。

## 参考アレンジ

`misc/ClubCovenArranged.mp3`（約 212 秒）を比較に使用しました。拍周期は原曲と同じ 0.5 秒です。32〜96 秒の 35〜120 Hz と 300〜900 Hz のエネルギー比は原曲が −7.3 dB、参考版が −1.8 dB でした。参考版の 96〜120 秒では +1.2 dB まで上がります。この低域の前後関係を参考に、低音主体の展開から旋律が戻る流れを追加しました。再生に使う音は元の `ClubCoven.mp3` 由来の素材と合成音です。

## キャッシュと比較

起動時に `.cache/track.npz` を再利用します。MP3のハッシュ、編集した設定、解析コードが変わると自動で再生成します。強制再生成には `python play.py --rebuild-cache` を使います。

`python -m unittest -v` で回帰テストを実行できます。今回の改修前後と旋律置換の比較は [旋律置換と長時間演奏の評価](evaluation/performance/README.md)、強度別と音源分離の比較は [前回の評価結果](evaluation/README.md) にあります。

## 確認範囲

同一シードでの出力一致、シード差、原曲と処理済み伴奏それぞれのループ接続のサンプル連続性、出力ピーク、約 2 時間分のオフライン描画を確認しました。処理済み伴奏では、推定した旋律の基音・倍音付近が処理前より約 20 dB 下がり、150 Hz 未満は測定上ほぼ同じでした。既定の音声デバイスへの短時間出力も確認しました。長時間の実時間再生と、試聴による音楽的な自然さの評価は未実施です。
