# 編曲生成の比較

音量差を除いた反復を比較するため、シード17・44・108で旧方式と新方式を各30分ずつ、計3時間分描画した。イントロ後の完全な891小節を各回の集計に使った。

| 指標 | 旧方式 | 新方式 |
| --- | ---: | ---: |
| 最頻の小節パターンの割合 | 7.4〜14.5% | 11.4% |
| 8〜64小節前に類似小節があった割合 | 85.5〜86.2% | 89.2〜89.6% |
| 原曲ミックスを使った小節 | 20.0〜31.4% | 20.0〜31.3% |
| 同じ演奏構成の継続小節数の中央値 | 102 | 102 |
| 最大サンプルピーク | 0.744〜0.811 | 0.726〜0.777 |
| 30分分の描画時間（同一環境） | 0.64〜0.75秒 | 0.68〜0.93秒 |

小節の比較には、原曲の使用有無、実際に鳴った主旋律・伴奏の音色、ベース・和音・キック・その他の打音が鳴った8分音符位置を使った。これらの音色と原曲使用の条件が同じで、4層の発音位置の重なりが75%以上なら類似とした。7小節以内は除外し、フレーズ内で意図的に反復する箇所の影響を抑えた。継続小節数は旧方式のスタイル、新方式のセクション構成を単位にした。構成の維持期間を204秒に伸ばしたため、範囲内で類似小節が再出現する割合も上がった。和声の回帰はシード44で4小節確認できた。

描画時間はオフラインの一括計測。これらの数値で、音楽的な自然さや長時間試聴時の印象は判定できない。新方式の回帰は、合成伴奏中に入口と出口の和声を確認できる1組で有効にしている。録音セクションの移動や、複数経路の選択には追加検証が必要。

## 比較試聴

同じシードの8分間を音量補正なしで書き出す。既定の切り替えは2:48.375と6:12.375。前後を聴き比べると、編曲を維持する区間と切り替えの両方を確認できる。

```powershell
python play.py --legacy --seed 44 --seconds 480 --preview evaluation/legacy-generation.wav
python play.py --seed 44 --seconds 480 --preview evaluation/procedural-generation.wav
python evaluation/compare_generation.py
```
