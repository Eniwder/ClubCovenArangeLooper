# 編曲生成の比較

音量差を除いた反復を比較するため、シード17・44・108で旧方式と新方式を各30分ずつ、計3時間分描画した。イントロ後の完全な891小節を各回の集計に使った。

| 指標 | 旧方式 | 新方式 |
| --- | ---: | ---: |
| 最頻の小節パターンの割合 | 7.4〜14.5% | 1.8% |
| 8〜64小節前に類似小節があった割合 | 85.5〜86.2% | 18.1〜21.3% |
| 原曲ミックスを使った小節 | 20.0〜31.4% | 15.3〜19.1% |
| 同じ演奏構成の継続小節数の中央値 | 102 | 8 |
| 最大サンプルピーク | 0.744〜0.811 | 0.791〜0.842 |
| 30分分の描画時間（同一環境） | 0.55〜0.61秒 | 0.79〜0.83秒 |

小節の比較には、原曲の使用有無、実際に鳴った主旋律・伴奏の音色、ベース・和音・キック・その他の打音が鳴った8分音符位置を使った。これらの音色と原曲使用の条件が同じで、4層の発音位置の重なりが75%以上なら類似とした。7小節以内は除外し、フレーズ内で意図的に反復する箇所の影響を抑えた。継続小節数は旧方式のスタイル、新方式のセクション構成を単位にした。新方式では全8種の拍の解釈が3シードすべてに出現し、和声の回帰はシード44で8小節、108で4小節確認できた。

描画時間はオフラインの一括計測。これらの数値で、音楽的な自然さや長時間試聴時の印象は判定できない。新方式の回帰は、合成伴奏中に入口と出口の和声を確認できる1組で有効にしている。録音セクションの移動や、複数経路の選択には追加検証が必要。

## 比較試聴

同じシードの8分間を音量補正なしで書き出す。まず0:24〜2:48で新方式のセクション間の違い、次に2:48以降で両方式の長期スタイル内の展開を比べられる。

```powershell
python play.py --legacy --seed 44 --seconds 480 --preview evaluation/legacy-generation.wav
python play.py --seed 44 --seconds 480 --preview evaluation/procedural-generation.wav
python evaluation/compare_generation.py
```
