## 解析・音源分離

採譜は16分音符のグリッド上で、推定旋律、休符、発音フラグ、残り持続長を保存する。音高が同じでもエネルギーが上がる箇所を再発音の候補にし、持続中は小節をまたいでも打ち直さない。伴奏にはベース、上声、クロマから推定した和音構成音を使う。原曲のセクションと保護するフィルは手動のマーカーで記録した。

原曲30.750秒からの24秒を CPU 上の Demucs `htdemucs` で4ステムに分離した。推定旋律付近と低域の値は、原曲に対する同一ゲインでのエネルギー測定。リンク先の試聴ファイルは別途 −21 LUFS に調整した。

| 音源 | 推定旋律付近の変化 | 150 Hz未満の変化 |
| --- | ---: | ---: |
| [比較区間の原曲](separation-original.wav) | 0 dB | 0 dB |
| [周波数マスクによる伴奏](separation-spectral.wav) | −20.3 dB | 約0 dB |
| [Demucsのベース＋ドラム](separation-demucs-rhythm.wav) | −24.7 dB | −1.1 dB |
| [Demucsのその他ステム](separation-demucs-other.wav) | — | — |

Demucsのベース＋ドラムは旋律をさらに抑えられる一方、和声を含む「その他」ステムをまとめて外す。今回は、低域を保ちつつ伴奏の情報を残せる周波数マスクを通常の再編曲に使い、完全なブレイクには既存の合成ベースと抽出打音を使う。分離は24秒の比較に限定し、ボーカル、ストリングス、旋律の個別ステムの純度は未検証。再生時にはモデルを読み込まない。 [Demucs公式実装](https://github.com/facebookresearch/demucs)

音色は既存の合成音を調整し、鍵盤に緩いデチューン、アルペジオに短いステレオの反射音を足した。SoundFontやサンプル音源は導入せず、音色の違いは上の試聴で判断できるようにした。

## 実測

Windows、Python 3.11、48 kHz。計測スクリプトは `python evaluation/benchmark.py --device`。オフラインはシード42・44・117で各2時間相当。実機は512フレーム条件で12秒間。

| 項目 | 改善前 | 改善後 |
| --- | ---: | ---: |
| 素材準備 | 2.76秒 | 冷間3.11秒、キャッシュあり0.15〜0.17秒 |
| キャッシュ | — | 141.4 MB |
| 実機出力中のワーキングセット | 182.2 MiB | 185.4 MiB |
| 実機コールバック p99 / 最大 | 0.143 / 0.226 ms | 0.107 / 0.162 ms |
| PortAudio負荷 | 0.56% | 0.48% |
| 実機アンダーラン | 0 / 1122 | 0 / 1122 |
| オフライン2時間分の描画 | 3.41〜3.53秒 | 3.60〜3.78秒 |
| オフライン最大絶対振幅 | 0.857 | 0.963 |
| 絶対振幅0.001未満が続いた最長時間 | 0.85秒 | 0.85秒 |

改善後のPython追跡メモリは描画約170秒時点が3.7 kB、約768秒時点が7.5 kBで、制作済み音源は固定。履歴はスタイル48件・強度操作256件が上限。測定した処理時間はバッファの10.7 msを下回ったため、先行レンダリングやリングバッファは追加しなかった。

試聴用音量とは別に、各スタイルの区間ラウドネスを計測してプラック、ベースブレイク、打音ブレイクなどを固定ゲインで調整した。休符やブレイクの静けさは残す。冒頭とループの波形連続性、シードと操作ログによる再現性、境界値、キャッシュ、WAV出力などは `python -m unittest -v` で確認できる。

旋律と和音はステレオミックスからの推定で、細かな発音位置と音の正誤は人による採譜と比較していない。音楽的な自然さ、分離残りや音色の評価、および長時間の実時間再生は今後の試聴項目に残る。
