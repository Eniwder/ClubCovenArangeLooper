# 旋律置換と長時間演奏の評価

## 同じフレーズで比較

冒頭4本は、原曲48.375秒からの同じ8小節。全ファイルを −21.0 LUFS に調整した。

| 試聴 | 内容 |
| --- | --- |
| [原曲](same-phrase-original.wav) | 旋律と伴奏を含む元のミックス。 |
| [従来の旋律抑制](same-phrase-mask.wav) | 周波数マスクを適用した伴奏。 |
| [再構成した伴奏のみ](same-phrase-accompaniment.wav) | ベース、和声音、短い合成打音。 |
| [鍵盤による旋律置換](same-phrase-piano.wav) | 上と同じ伴奏、シード、区間に鍵盤の旋律を加えた出力。 |
| [弦による旋律置換](same-phrase-strings.wav) | ビブラートと重なりを持つ長めの音、持続系の伴奏。 |
| [ベルによる旋律置換](same-phrase-bell.wav) | 短い経過音を間引き、節目の音に長い余韻を残す。 |
| [鍵盤と弦の交代](same-phrase-exchange.wav) | 共通のベースリズムの上で、4秒ごとに担当楽器を交代する8秒の抜粋。 |

置換・交代・省略はいずれも、原曲ミックスが約250 msで消えたあと、合成した伴奏と楽器だけが鳴る。回帰テストでは元の波形を無音に置き換え、原曲から抽出した打音を外しても、鍵盤置換と伴奏のみの出力がそれぞれ完全に一致した。音色の残留と、共通の旋律を新しい楽器が鳴らすことはこの方法で区別できる。

## 長時間で比較

- [改善前 4分](before.wav) と [改善後 4分](after.wav) は同じシード44、編曲強度100%、−21.0 LUFS。
- 改善後の **0:24** から主旋律のないアンビエント、**0:40** から鍵盤と弦の交代、**0:48** から鍵盤が主旋律を担当する。**2:28** に原曲へ戻り、**2:56** にベル、**3:28** に弦が主旋律を担当する。
- [12分間の演奏](twelve-minutes.wav) はシード42、編曲強度100%、−21.0 LUFS。休息・展開・上昇・解放・回帰などが前後の履歴や原曲の区切りに応じて変わる。

通常の再生は5つの方式を持つ。原曲演奏では原曲に主旋律を任せる。旋律補強には原曲に鍵盤を重ねる専用スタイルを使い、出現重みを低く設定した。置換、交代、省略では同じ原曲ミックスを引き継がない。長期制御では直近6件のスタイルと担当音色、直近3件の展開状態を参照する。同じスタイルを継続として再選択した場合でも、継続時間を数え直す。

推定旋律は候補の競合と音高の連続性、和音は上位候補の差から信頼度を付けた。4小節の旋律信頼度を置換候補の重みに反映し、短く曖昧な装飾音を減らす。和音候補が競合する拍ではベース中心の伴奏にする。信頼度は曲内での相対的な目安で、正答率としては検証していない。

## 検証

- 回帰テスト10件に合格。同一シードと操作履歴での再現性、バッファサイズ不変、ループ境界、音符の持続、再選択の時間計測、演奏主体の交代、波形の非混入を確認。
- 3シードを各2時間分、合計6時間分オフライン描画。最大絶対振幅0.965、最長のほぼ無音区間0.85秒。
- 12秒の実機出力でアンダーラン0回。512フレーム時のコールバックはp99 0.116 ms、最大0.216 ms。短時間の計測でワーキングセット225.6 MiB。 [計測ログ](benchmark.txt)

録音から保持される元の伴奏の細かな演奏や音色は、再構成区間では変わる。推定採譜の誤り、合成音の聴感、展開の自然さは実耳での確認が残っている。元のMP3と以前の評価音源はそのまま保存している。
